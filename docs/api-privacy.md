# OpenAI APIの送信情報と料金

shakyoは、解説の実行時に選択したコード（未選択なら全文）と解説用の指示をOpenAI APIへ直接送信します。追加質問では元のコード、過去の質問と回答、今回の質問も送信します。機密情報を含むコードは送信前に確認してください。

Web版のAPIキーは実行中のタブのメモリだけに保持され、再読み込みで消去されます。デスクトップ版ではOSの資格情報ストアに保存し、Rust側からOpenAI APIへ送信します。既存のlocalStorageキーは資格情報ストアへの保存成功後に削除します。保存できない場合は旧キーを残し、AI解説を停止します。shakyo開発者のサーバーは経由しません。参照先Webサイトや、通信を許可した拡張の通信は別の扱いです。

OpenAI APIのデータは、明示的な共有への同意がない限り、既定ではモデル学習に使用されません。不正利用監視ログは通常最大30日保持され、法的義務などの例外があります。保存されないことを保証するものではありません。詳細は[公式のデータ利用方針](https://developers.openai.com/api/docs/guides/your-data)を確認してください。

API利用料はChatGPTのサブスクリプションとは別です。モデル、入力・出力・推論トークン数、会話履歴の長さで請求額が変わります。モデル切り替えにより単価が上がる場合があります。shakyoには請求額の上限を強制する機能はありません。[料金](https://developers.openai.com/api/docs/pricing)と[利用状況](https://platform.openai.com/usage)を確認してください。

モデル選択は入力間違いを防ぐための候補であり、アカウントのアクセス権や将来の提供継続を保証しません。既存の保存済みモデルは自動変更しません。
